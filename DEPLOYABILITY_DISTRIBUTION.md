# Deployability and Distribution

## Deployability

- The release is a static ES-module application with zero runtime package dependencies.
- No account, server state, external API, or production secret is required.
- `npm run validate` executes the deterministic planner/export tests and builds `dist/`.
- Nginx and GitHub Pages deployment definitions are included.
- Rollback is restoration of the prior static artifact.

## Distribution

Activation is generation and export of the first three-day plan. Useful surfaces include founder/operator workshops, direct artifact delivery, project retrospectives, and repository planning guides. Workspace export provides a handoff path without shared infrastructure.

## Remaining external proof

A cold user must still validate whether the scoring vocabulary and three-day capacity model match their working context. The release makes no claim that a high score predicts commercial or operational impact.
